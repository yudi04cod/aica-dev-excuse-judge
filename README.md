One funny single-line excuse a developer gives when code breaks in
production — entry for the make.fun bounty
[Make the AI Judge Laugh: Developer Excuses](https://make.fun/bounty/u-motasimfuad-make-the-ai-judge-laugh-developer-49386be3).

`main.py` (Python standard library only) writes the excuse to
`/output/entry.txt`:

> It worked in staging because staging is just my laptop with a fancier hostname — and my laptop has never met a real user, a real timezone, or a real database.

Run it with:

```sh
python3 main.py
```
